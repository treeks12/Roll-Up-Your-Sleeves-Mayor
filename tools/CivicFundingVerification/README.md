# Native civic funding verification

Run `./tools/CivicFundingVerification/Run-Checks.ps1`. Outputs and intermediates stay in `.cache/civic-funding-verification`; `-WorkDirectory .cache/review-civic-native` gives a separate reviewer directory. The script loads installed DLLs as metadata/read-only references and runs the isolated executable with the bundled Mono. It never builds the Mod or Simulation projects, initializes/queries/patches a provider, changes game files, installs anything or launches CS1.

The two actual backend sources and three actual pure evaluator/ledger/codec sources are compiled into the isolated executable. Only provider-preparation boundaries are inert stubs. The tests check exact rational integer outputs, independent current/average inheritance including mutable native day/night weights, original byte retention and valid-ledger retries after storage failure. Managed uninitialized AI objects are used only as type tags for arithmetic; no Unity constructor or AI method is called.

The harness decodes the installed methods' actual IL with labels, invokes the actual seven civic transpiler paths and proves consistent evaluation-stack heights across their control-flow edges. It checks the original RNG call count, the two raw cure denominator reads, four effective hospital-capacity consumers, actual AddResource call sites and the one maintenance FetchResource wrapper. A malformed call shape must fail. Injected call-boundary labels and exception-block metadata must move to the first additional argument.

Scope tests cover the pure full-identity/reference predicate, declined sentinels, nested finalizer restoration and single-use admitted-cycle counters. The bookkeeping fixtures deliberately set private installation flags but never call a provider. They do not prove that hooks were installed or that native effects occurred. Live-city effects, installed clinic/hospital names/parameters, native offers, cash/expenses and patient allocation require the separate owned-city QA.

## Deliberate runtime boundaries

The enabled backend supports exact SchoolAI education levels 1/2. Exact HospitalAI health facilities use the explicitly authored exact-name mapping `Medical Clinic` to Clinic and `Hospital` to Hospital; name presence/parameters must be demonstrated by the native inventory. University, derived campus/medical-center types, childcare, eldercare, events and other hospital names retain native behavior.

Local percentages are 0..120; each inherited axis independently uses the actual global current or weighted-average budget (0..255), as appropriate to its consumer. Integer E consumers use exact units per 200 and one final ceiling; maintenance uses the evaluator's final integer truncation after the native policy adjustment. AddResource coverage uses average coverage, while current range uses current coverage. Coverage affects resource-map deposition, not the dispatch distance of student/sick transfer offers. The raw patient capacity remains the cure denominator. Patient capacity itself does not depend on finalProductionRate; curing and ambulance targets do. The finalProductionRate arguments and native RNG draw sites are untouched.

`LastRequestedMaintenanceCost` is the amount after the civic share and before the native EconomyWrapper. `LastMaintenanceAvailability` is the unmodified FetchResource return used for affordability. It is **not cash paid**: the native method debits its amount even when availability is lower, and another EconomyExtension may alter that amount. Cash/expense deltas need separate native evidence. Amounts retain native internal currency and maintenance-period units.

Prepare installs an inert complete hook set outside runtime/bridge locks; failed partial installs roll back only the owned Harmony ID. Start only consumes a prepared lease and binds an idle owner atomically. Stop disables new scopes and commands. An admitted scope finishes its captured mapping, including nested production, through its finalizer; a declined scope stays native even if an owner starts later. Managed-cycle counts prevent a new owner binding across an old cycle. Last-lease release with admitted work leaves the hook set resident and inert; finalizers only decrement bookkeeping. A later outside-lock preparation may reuse that set. This is a bounded admitted-scope rule, not universal atomicity for arbitrary CPU entry or provider changes.

Hospital increases invoke the native EnsureCitizenUnits path only after validating the current unit chain. Visit storage is counted again afterward; allocation failure suspends effects instead of claiming the requested slots exist. Units and residents are never removed. The bounded building reconciliation scans 512 slots per call; supported hospital chains are additionally traversed before controlled production and on reconciliation. Large-city performance is not established by these isolated checks.
