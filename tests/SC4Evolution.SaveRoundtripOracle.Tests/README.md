# Save/reload authority oracle checks

The native driver now expects `SC4Evolution.EconomicPair.v1` as its authoritative class/capacity storage. It copies the exact stored/live envelopes and decodes them with the production envelope helper plus real reviewed class/capacity codecs. The legacy class key is optional and must remain byte-identical if present; its presence cannot substitute for authority or demonstrate a newly written legacy key.

This pure executable links only `EconomicSaveRoundtripOracle.cs`, the real envelope helper and Simulation project. It does not compile/run the full native SaveReload driver, touch a city, launch Cities, build the Mod or create a populated fixture. Historical 0.4 native evidence remains unchanged and is not relabeled as proof of this new layout.

From the project root:

```powershell
. ./scripts/Enter-Project.ps1
dotnet run --project tests/SC4Evolution.SaveRoundtripOracle.Tests --artifacts-path .cache/save-roundtrip-oracle/artifacts
dotnet build tests/SC4Evolution.SaveRoundtripOracle.Tests -p:TargetFramework=net35 -p:TargetFrameworks=net35 -r win-x86 --artifacts-path .cache/save-roundtrip-oracle/net35
```

Both net10 and the net35 executable on bundled Mono passed **403 checks**. Coverage: exact envelope and inner byte identity, valid bound capacity versus explicit legitimate absence, absent/corrupt/partial authority rejection despite a legacy entry, stale/different valid class or capacity rejection, optional legacy preservation/create/remove/change refusal, every authoritative byte individually corrupted and truncated reload entries. The net35 harness built with zero warnings/errors. Running it on bundled Mono requires the game's `Cities_Data/Managed` directory on temporary MONO_PATH for System.Core, restored afterwards.

The native driver retains its original session/frame/date/cash/forced-pause/native-identity criteria and report/cleanup sequencing. New manifests label `oracleLayout` and report separate hashes/lengths for the stored/live authority, embedded class/capacity payloads and optional legacy key. Legitimate absent capacity explicitly reports that capacity persistence was not exercised. No native save/reload success is established by this pure harness; integration compilation and a new live run remain separate work.

## Explicit stable populated-capacity restore expectation

The production oracle now additionally exposes:

```csharp
byte[] PrepareStableCapacityRestore(byte[] saved, bool rawMode);
void RequireRestoredWithExpectedLive(byte[] saved, byte[] restoredStored,
    byte[] expectedLive, byte[] restoredLive, byte[] legacySaved, byte[] legacyRestored);
```

The original RequireRestored remains unchanged and requires saved/stored/live byte equality. The new opt-in path requires a present bound capacity payload with nonempty records, all Completed. It uses only the saved envelope and declared branch. RAW is pure Restore(epoch 1) → checked ExternalRevision+1 → acknowledgment of saved StockRevision/new ExternalRevision → capture/real codec write using exactly the original class bytes. Shadow performs Restore/capture without external advancement or acknowledgment. No clock, census, observed live bytes, mutable configuration, native code or provider is read. CRC and envelope digest are generated by the production codecs.

The driver must clone/freeze/hash expectedLive BEFORE loading and prove the stable-native/first-converged-census prerequisites described in analysis/capacity-populated-roundtrip-plan.md. This stateless signature cannot establish when its expected byte array was computed or which mode the native driver actually ran. RequireRestoredWithExpectedLive checks exact saved storage, unchanged saved/expected/live class bytes, exact expected/live capacity/envelope bytes and exact optional legacy bytes. It never derives expected from restoredLive. The caller's pre-load provenance and native-mode proof remain mandatory; no arbitrary observed-diff tolerance is introduced.

The expanded suite passes **1,459 pure checks** on net10 and bundled Mono/net35. Stable fixtures contain three real-codec Completed records across all classes with Selected/Imported origins; no native city/citizens are created. Golden expected wire states are assembled independently as DTOs, rather than repeating the production Restore call. Checks cover Open/Exhausted/Invalidated/NotQualified/null windows, distinct days/opening revisions, retained RAW/overbuild float bits including negative zero, unchanged committed quota, no same-day reopening/refund, stable record/history identity, RAW and Shadow publication revisions, maximum-revision Shadow retention versus checked RAW overflow, required nonempty/completed records, absent capacity, crossed payloads including same GUID/different exact class hash, repaired-CRC unknown policies/profiles, every populated-envelope byte individually corrupted and forbidden live/legacy/storage changes.

Use `.cache/save-roundtrip-oracle/stable-restore-net10` and `.cache/save-roundtrip-oracle/stable-restore-net35` as isolated artifacts paths in the commands above. The net35 harness builds with zero warnings/errors and runs on bundled Mono with temporary MONO_PATH as described. No Mod build, preview, installation, native save/reload or provider activation was performed for these checks.
